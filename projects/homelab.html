What It Does

This project turns a Raspberry Pi into an always-on network hub that mirrors the kind of monitoring and operations infrastructure I've run professionally in enterprise NOC environments. The goal was to stop relying on my desktop being on for DNS, monitoring, and services — and to have a real lab environment to practice and extend skills at home.

The Pi (hostname: uzi, Raspberry Pi 4) runs a 15-container Docker stack including Pi-hole + Unbound for DNS-level ad blocking, Prometheus + Grafana for metrics and dashboards, a Cowrie SSH honeypot on port 22, fail2ban for automated banning, Nextcloud for personal cloud storage, Gitea for self-hosted Git, ntfy for push alerts, and Nginx Proxy Manager as the reverse proxy. The TankPit Discord bot runs here too — migrated from Railway. Watchtower handles automatic container updates at 4am. Remote access is Tailscale only — no inbound ports.

October 2026 incident: after a router DHCP change the Pi moved addresses, and once it was pinned back with a reservation it froze — kernel still accepting TCP, nothing in userland answering. Root cause was memory: 15 containers on 1.8 GB RAM with swap pinned near 100%. I power-cycled it, shed the two heaviest monitoring agents (Netdata, cAdvisor), and load dropped from ~16 to ~1.4. A second issue surfaced along the way: desktop DNS queries reached the Pi over the Tailscale subnet route, so Pi-hole dropped them as "non-local" — fixed by changing its listening mode. Next step is moving the stack to a mini PC and keeping the Pi as backup DNS.

The Docker Stack

Pi-hole · :8053
Network-wide DNS sinkhole. 1,614,089 unique domains blocked across 10 blocklists including StevenBlack, AdGuard, OSINT, Hagezi Pro, and Hagezi TIF. Desktop and iPhone use Pi-hole as primary DNS. Unbound on :5335 as upstream recursive resolver (DNSSEC).
Grafana · :3001
Security NOC dashboard showing Cowrie attack data, fail2ban bans, nmap network scans, and host metrics via Node Exporter. Home dashboard: Docker & Host Monitoring.
Prometheus · :9091
Metrics backend scraping node-exporter (system metrics) every 30s. 30-day retention. Powers the Grafana dashboards. cAdvisor container metrics are paused to save RAM.
ntfy · push alerts
Self-hosted push notifications to my phone over Tailscale: new devices found by the daily nmap scan, backup failures, and container down/recovered events from a 5-minute watchdog.
Cowrie · :22
SSH/Telnet honeypot running on port 22. Logs every brute-force attempt, credential pair, and command run by attackers. Real SSH is on port 2022. fail2ban bans repeat offenders for 24h.
Nextcloud · :8080
Self-hosted personal cloud with MariaDB backend. Nightly rclone backup to OneDrive with push alerts on failure; a silent month-long outage traced to an expired OAuth grant plus a distro rclone too old for OneDrive's 2024 upload-session change, fixed by re-authorizing and pinning the upstream build. Accessible on LAN and via Tailscale from iPhone.
Netdata · paused
Real-time telemetry with the desktop streaming to the Pi as a parent node. Paused in October 2026 to free memory; returns on the new server.
Gitea · :3000
Self-hosted Git server mirroring all active repos (tankpit-bot, portfolio, dotfiles). Push hooks dual-write to both GitHub and Gitea simultaneously. Offline backup in case of GitHub outage.
Nginx Proxy Manager · :80/:81
Reverse proxy and SSL termination for all Pi-hosted services. Routes portfolio.home → nginx-portfolio and handles internal service URLs on the LAN.
TankPit Bot · background
Discord bot migrated from Railway to Pi Docker. Runs python bot.py with SQLite DB and RAG bible mounted as volumes. Restart policy: unless-stopped.
Watchtower · background
Automatic Docker image updates at 4am daily. Checks for new image versions, pulls, and restarts containers with zero manual intervention. Keeps the stack patched and current.

Network Inventory & Segmentation

Part of this project was a full audit of the 192.168.1.0/24 subnet — identifying every device, classifying it as trusted, IoT, or unknown, and planning VLAN/SSID segmentation using the router's built-in IoT WiFi network.

Trusted Devices
Desktops, laptops, phones and tablets on the primary 5 GHz network. Full LAN access, Pi-hole DNS enforced.
IoT / Media → IoT SSID
Cameras, smart plugs and diffusers, speakers, printer and kids' devices move to the router's isolated 2.4 GHz IoT network; streaming TVs stay on 5 GHz.
Flagged / Unknown
Any device that can't be tied to an owner by MAC vendor and behavior is flagged and blocked at the router until identified.
Infrastructure & Hardening
Pi pinned by DHCP reservation, wired only. Verizon router plus a Fios Wi-Fi extender. Hardening pass under way (October 2026): guest network, UPnP off with one explicit Tailscale forward, WPS off.

Roadmap

SNMP + Grafana
Python SNMP poller targeting the Verizon router and any managed devices. Feed into existing Prometheus + Grafana stack. Mirror the SolarWinds NPM/NTA interface-level traffic view from production.
Suricata NIDS
Network intrusion detection system on the Pi. Passive traffic analysis on LAN to detect port scans, ARP spoofing, and known CVE signatures. Feed alerts into Grafana Security NOC.
IoT Segmentation
Migrate all IoT devices to the Verizon built-in IoT SSID. Reduces attack surface — compromised smart device can't reach desktop or Pi on the primary subnet.
Move Off the Pi
Migrate the stack to a low-power mini PC running Proxmox; the Pi becomes a backup DNS resolver so one box failing can't take the house offline. Repurposed ex-mining GPUs become an on-demand local AI node.
3-2-1 Backups
Restic / Proxmox Backup Server to local disk plus an off-site copy, with every job reporting failures to ntfy instead of failing silently.
Isolate the Honeypot
Move Cowrie off the box that holds personal data — onto its own VLAN or a small cloud VPS.

What I Learned

Running a homelab is the fastest way to understand why enterprise networking decisions get made. I locked down DNS on my home network the same week I was troubleshooting a Verizon router that doesn't allow custom DHCP DNS servers — which is exactly the kind of ISP-side constraint we dealt with at ViaPath when coordinating with LECs.

Docker Compose taught me that container orchestration at small scale is more about operational discipline than technical complexity. Watchtower auto-updates, Nginx Proxy Manager for SSL, and volume mounts for persistence are the same patterns that appear in Kubernetes at scale.

Finding an unidentified device on my own LAN was a real moment — an unknown device with no owner is exactly what Splunk SIEM alerts are designed to catch in production. The homelab makes the professional context click.

The October 2026 freeze taught the oldest NOC lesson again: capacity planning is part of reliability. Every container I added was cheap on its own, and together they put the single box I depended on for DNS into swap until it stopped answering. Monitoring didn't catch it because the monitoring agents were part of the load.
